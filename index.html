Esta demostración funciona sin servidor ni cuenta. Los datos se conservan únicamente en el almacenamiento local del navegador, no se envían a ninguna institución. No representa un sistema seguro para almacenar datos reales de alumnos. Para uso institucional hacen falta autenticación, permisos por rol, respaldo, auditoría, protección de datos y validación de integraciones.
